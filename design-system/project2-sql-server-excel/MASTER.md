# Project2 SQL Server Excel 设计系统

本文件是项目界面的视觉与交互基准。页面级规范如存在，应放在同目录的 `pages/` 下，并仅覆盖该页面的特殊规则。

## 产品定位

- 产品：企业内部只读数据查询与 Excel 导出工具。
- 用户：中国非技术业务人员。
- 风格：克制、可信、清晰、高信息密度的企业工作台。
- 设计方向：Minimalism / Swiss Style，避免装饰性渐变、玻璃拟态和夸张动效。
- 设计参数：视觉变化度 3/10，动效 2/10，信息密度 7/10。

## 设计原则

1. 业务路径始终按“模块 → 查询事项 → 查看字段 → 筛选条件 → 结果 → 导出”展开。
2. 每个页面只保留一个主要操作；“生成 Excel”和“下载 Excel”是结果阶段的主操作。
3. 数据库表名、字段名、SQL、JOIN 和连接信息不得进入普通用户界面。
4. 所有表单保留可见中文标签、帮助文字和就近错误提示。
5. 状态不能只依赖颜色表达，必须同时提供明确中文文字。
6. 白天和夜间主题同步设计、分别验收。

## 字体与数字

- 不加载 Google Fonts 或其他外部字体，保证 Windows 内网离线部署稳定。
- 字体栈：`Segoe UI`、`Microsoft YaHei`、`PingFang SC`、`Noto Sans CJK SC`、系统无衬线字体。
- 正文基准 16px，行高 1.5–1.7。
- 标题权重 600–700，正文 400，标签 600。
- 行数、页码、金额等数据使用等宽数字特性。

## 间距与尺寸

- 基础间距采用 4px / 8px 体系。
- 常用间距：4、8、12、16、24、32、48px。
- 输入框和按钮最小高度 44px。
- 卡片圆角 14px，输入和按钮圆角 9–10px。
- 桌面内容最大宽度约 1540px；窄屏不允许产生横向滚动。

## 组件规范

### 按钮

- 主按钮：企业蓝底、白字，仅用于当前阶段的唯一主要操作。
- 次按钮：表面色背景、清晰边框；悬停时使用浅蓝状态层。
- 禁用按钮降低强调度并显示不可操作状态。
- 键盘焦点使用至少 2px 的可见轮廓，不移除浏览器焦点反馈。

### 卡片

- 白天使用白色表面与轻边框；夜间使用深蓝灰表面与可辨识边框。
- 阴影只用于建立层级，保持低对比、低扩散。
- 卡片悬停不得缩放或改变布局尺寸。

### 表单与筛选

- 标签始终可见，示例只作为占位提示，不替代标签。
- 复杂帮助内容折叠展示，保持渐进披露。
- 附加条件使用左侧主色边界表达层级，不使用强烈整块强调色。
- 已选字段使用独立摘要区域，并始终显示数量和完整中文名称。

### 结果与数据表

- 匹配行数与分页进度使用数据摘要组件呈现。
- 空状态说明下一步操作，不出现无解释的空白区域。
- 数据表边框、表头和数值应在白天/夜间模式下保持清晰。
- “生成 Excel”前明确说明导出的是全量匹配数据。

## 响应式与动效

- 验收宽度：375、768、1024、1440px。
- 小屏优先显示主题选择、页面标题、查询设置，再显示结果。
- 动效仅用于悬停、焦点和状态变化，时长约 160ms。
- 仅改变颜色、边框、阴影或透明度，不使用造成布局移动的动画。
- 必须尊重 `prefers-reduced-motion: reduce`。

## 禁止项

- 不使用 Emoji 作为结构性图标。
- 不加载外部字体、图片或动画库。
- 不使用红色作为普通选中状态或主要按钮颜色。
- 不使用低对比灰字、不可见焦点、无标签输入框。
- 不用颜色单独表达成功、警告或错误。
- 不为视觉效果修改查询、筛选、分页、导出和只读安全逻辑。

## 交付检查

- 全部自动化测试通过。
- 白天与夜间主题分别检查。
- 375px 和 1440px 无横向滚动。
- 输入框、下拉框、复选框、按钮和标签具有统一状态颜色。
- 键盘焦点清晰，控件最小高度 44px。
- 页面无外部 UI 依赖，Windows 服务器可离线渲染。
